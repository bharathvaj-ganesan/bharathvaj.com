[Dilum Sanjaya](https://x.com/DilumSanjaya) built [Designed to Scale](https://designed-to-scale.vercel.app/), an interactive system design course. Each lesson is an animated diagram you step through, so you watch a design grow from one server to millions of users instead of reading about it.

It covers load balancing, caching, sharding, consensus, queues, and whole-system designs like a URL shortener, a news feed, and a chat system. At the time of writing, only a couple of modules are marked ready, so more are coming.

Dilum has built other cool things like [dilum.dev](https://dilum.dev/) that make it easy to understand the fundamentals. Dilum's other interactive primers:

- [Algo Lab](https://byte-sized-algorithms.vercel.app): data structures and algorithms, step by step
- [Protocol Explorer](https://protocol-explorer-alpha.vercel.app): HTTP, DNS, TCP, TLS and more, packet by packet
- [Electronics 101](https://electronics-101-six.vercel.app): electronics from scratch on a 3D workbench
- [Backcountry 101](https://backcountry-101.vercel.app): survival skills, step by step, in 3D

Visualization matters. It looks like a good way to learn system design if you prefer to see how things work than to read about them.
